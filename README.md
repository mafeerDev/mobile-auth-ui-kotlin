# Android Auth Flow Kotlin

Android mobile application featuring authentication UI screens with navigation.

## Features

* Login screen
* Signup screen
* Field validations
* Show / hide password
* Forgot password flow
* Navigation between screens
* Modern mobile UI

## Tech Stack

* Kotlin
* Android Studio
* XML Layouts
* Navigation Components

## Purpose

This project was created to practice mobile authentication flows, UI design and screen navigation in Android.
